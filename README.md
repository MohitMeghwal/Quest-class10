## GitHub Pages पर वेबसाइट लाइव करने के आसान चरण:
1. GitHub पर एक नया Public Repository बनाएँ (जैसे `science-quest-10`)।
2. इस फ़ोल्डर की `index.html` (और `README.md`) फ़ाइल को उस Repository में Upload करें।
3. Repository की **Settings → Pages** में जाएँ।
4. **Source** में `Deploy from a branch` चुनें, Branch `main` और Folder `/ (root)` चुनकर **Save** करें।
5. 1–2 मिनट में आपकी वेबसाइट `https://<your-username>.github.io/science-quest-10/` पर लाइव हो जाएगी!
